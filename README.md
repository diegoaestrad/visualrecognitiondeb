# 👁️ Real-Time YOLO11 Object Detection

A streamlined Python application to perform real-time object detection using the latest [YOLO11](https://docs.ultralytics.com/) model. This tool allows users to select from available connected cameras and provides instant visual feedback with bounding boxes.

## 🚀 Features
*   **YOLO11 Inference:** Leverages the latest Ultralytics model for fast, accurate detection.
*   **Dynamic Camera Selection:** Automatically detects and lists available cameras, allowing you to choose the correct device at runtime.
*   **Live Feedback:** Displays an annotated real-time video stream.

## 🛠️ Requirements
*   Python 3.8+
*   `opencv-python`
*   `ultralytics`
